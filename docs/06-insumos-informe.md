# Antecedentes técnicos para el informe

- **Equipo:** Git Happens.
- **Tecnologías:** Kotlin, Jetpack Compose, Firebase Authentication, Realtime Database y Paho MQTT.
- **Flujos principales:** ingreso, pertenencia a una comunidad, chat, avisos, alertas en vivo e historial.
- **Mejoras de interfaz:** demostración, galería de espacios, información de conexión y seguimiento del estado de una alerta.
- **Evidencia existente:** pruebas unitarias y verificación manual de acceso con Google, perfil, chat y alertas. Consultar [resultados](04-pruebas.md).
- **Validaciones pendientes:** permisos de administrador y aislamiento, FCM, usabilidad, accesibilidad y rendimiento.
